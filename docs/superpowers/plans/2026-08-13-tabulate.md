# Tabulate Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a saved JMP-style Tabulate workspace that computes live multi-level cross-tabulations in DuckDB without creating a result dataset.

**Architecture:** A typed `tabulate` Tauri command delegates to a dedicated Rust service and a DuckDB aggregation method that returns a normalized matrix. React persists only the analysis configuration in Zustand/project JSON, derives hierarchical headers with pure helpers, and renders a three-column field/build/result workspace.

**Tech Stack:** Rust 2021, Tauri v2, DuckDB 1.10505.0, serde, React 19, TypeScript 5.7, Zustand 5, i18next, Font Awesome 6, Node built-in assertions.

## Global Constraints

- Tabulate is opened from `Analyze > Tabulate` and is enabled only when a dataset is active.
- The first release is non-destructive: it does not create a dataset, edit source data, accept SQL, or export results.
- Configuration changes debounce for exactly 250 milliseconds.
- The maximum interior result size is exactly 10,000 cells, excluding totals.
- Interior cell order is row-major, then column, then statistic: `((row * columnCount) + column) * statisticCount + statistic`.
- A missing row or column role contributes one synthetic empty member.
- Missing dimension values are represented by JSON `null` and sort after non-missing values.
- Standard deviation and variance use sample semantics.
- Quantile probability is finite and in the inclusive range 0 through 1.
- Percentages use the selected field's non-missing count; zero denominators return `null`.
- Rust commands return `Result<T, AppError>` and contain no `unwrap()` or `expect()` outside tests.
- SQL contains only backend-owned templates and metadata-validated, double-quoted identifiers; frontend values never become SQL fragments.
- Rust IPC models use `#[serde(rename_all = "camelCase")]`; TypeScript mirrors the serialized names exactly.
- Shared frontend state uses Zustand; components do not call Tauri directly.
- Do not commit or push unless the user explicitly requests it.

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq, Eq)]
#[serde(rename_all = "camelCase")]
pub enum StatisticKind {
    Count,
    MissingCount,
    UniqueCount,
    Sum,
    Mean,
    StandardDeviation,
    Variance,
    Minimum,
    Maximum,
    Median,
    Range,
    Quantile,
    RowPercentage,
    ColumnPercentage,
    TotalPercentage,
}

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
#[serde(rename_all = "camelCase")]
pub struct TabulateStatistic {
    pub id: String,
    pub field: String,
    pub kind: StatisticKind,
    #[serde(default, skip_serializing_if = "Option::is_none")]

}

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
#[serde(rename_all = "camelCase")]
pub struct TabulateRequest {
    pub dataset_id: String,
    pub row_fields: Vec<String>,
    pub column_fields: Vec<String>,
    pub statistics: Vec<TabulateStatistic>,
    pub include_row_totals: bool,
    pub include_column_totals: bool,
    pub max_result_cells: u64,
}

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
#[serde(rename_all = "camelCase")]
pub struct TabulateResult {
    pub row_members: Vec<Vec<serde_json::Value>>,
    pub column_members: Vec<Vec<serde_json::Value>>,
    pub statistics: Vec<TabulateStatistic>,
    pub cells: Vec<Option<f64>>,
    pub row_totals: Vec<Option<f64>>,
    pub column_totals: Vec<Option<f64>>,
    pub grand_totals: Vec<Option<f64>>,
    pub cell_count: u64,
    pub limit: u64,
}
```

`row_totals` uses `row * statisticCount + statistic`; `column_totals` uses

MissingCount        COUNT(*) - COUNT(field)

- [ ] **Step 4: Implement grouped cardinality before value materialization**

one for column members. No dimensions means cardinality `1`. Compute with
checked multiplication:

let cell_count = row_count
    .checked_mul(column_count)
    .and_then(|value| value.checked_mul(request.statistics.len() as u64))

if cell_count > request.max_result_cells {
    return Err(AppError::InvalidParam(format!(
        "Tabulate result has {cell_count} cells; limit is {}",
        request.max_result_cells,
    )));
}
```

  try {
    const next = await tabulateService.run(toRequest(item));
    if (sequence === requestSequence.current) {
      setResult(next);
      setError(null);
    }
  } catch (error) {

  } finally {
    if (sequence === requestSequence.current) setLoading(false);
  }
